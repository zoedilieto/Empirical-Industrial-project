Apart from this readme file, the folder contains the ai_usage.md, a do file, a Python notebook, a tex file, and a pdf (our writeup), all called ps2. It also contains the final dataset which was given to us. First, run the do file, make sure to replace the global PATH with the folder containing the final dataset. The do file generates the updated dataset and several of the tables the tex file reads. Then, run the ipynb file. If needed, run the first cell to install the necessary packages. The order is important because the python file reads the dta which already constructed the market shares and instruments, and this is constructed in the do file. Then, you can compile the tex file which reads the tex tables constructed by the do file, but we added the compiled pdf already.
